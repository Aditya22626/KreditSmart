# KreditSmart

Borrow smarter. Stay financially informed.

KreditSmart is an AI-powered loan discovery,
comparison and financial intelligence platform
designed for Indian consumers.

## Architecture

- Frontend: Next.js and TypeScript
- Backend: NestJS
- AI Service: Python and FastAPI
- Database: PostgreSQL
- Cache: Redis
- Cloud: Microsoft Azure

## Applications

- apps/web - Frontend application
- apps/api - Core backend API
- apps/ai-service - AI and document intelligence

## Development

This project is currently under active development.

## Disclaimer

KreditSmart is an informational platform.
It is not a lender or credit bureau.
Loan eligibility estimates do not guarantee approval.
